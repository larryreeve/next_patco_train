# PATCO Next

A small SwiftUI iOS app for finding the nearest PATCO station and showing upcoming trains for a selected station pair.

The bundled schedule was generated from PATCO's GTFS feed:

`https://rapid.nationalrtap.org/GTFSFileManagement/UserUploadFiles/13562/PATCO_GTFS.zip`

## Run

Open `NextPATCOTrain.xcodeproj` in Xcode, choose the `NextPATCOTrain` scheme, and run on a simulator or device.

The default commute is Ashland to 15/16th and Locust. Tap the location button to select the nearest station, or use the station menus and swap button manually.
